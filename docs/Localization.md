# 语言适配范围

设置 → 语言设置可立即切换并保存，或跟随系统。当前提供 28 种：简体中文、繁体中文、英语、日语、韩语、西班牙语、法语、德语、意大利语、葡萄牙语、俄语、乌克兰语、阿拉伯语、印地语、孟加拉语、乌尔都语、泰米尔语、泰卢固语、印尼语、马来语、越南语、泰语、土耳其语、波斯语、希伯来语、波兰语、荷兰语、菲律宾语。

这覆盖主要语言选项，并非全球全部语言或每个地区变体。未支持的系统语言回退英语。阿拉伯语、波斯语、希伯来语、乌尔都语使用从右到左布局。日期使用选中语言的格式；本地日历仍决定每日内容轮换。昵称、决定标题等用户输入保持原样。

## 已翻译与回退

- 主要导航、设置、显示选项、抽签模式、情绪选择、准备度标签、20 题和四级答案均有 26 种外语文本。
- 简体中文为原文；繁体中文优先用明确译文，其余由系统字形转换，不等同于台湾或香港地区的编辑审校。
- 非中文问卷采用与同一题号和维度对应的正向准备度陈述、四级符合程度，仍为 0–3 分。中文保留每题的具体四个答案。
- 其他界面字符串有英语回退。长篇星笺、部分报告说明、原创签诗、观音传统诗文和故事未全部翻成 28 种语言；缺译时保留原文。语言选择页已说明此范围，不能宣传“全文翻译完成”。
- 本问卷是自我观察工具，没有声称经过跨文化心理测量验证，也不作诊断或真实成功率预测。正式国际发行前应由各语言编辑审校语气、语义与长文本。

## 维护

`值得吗？/Resources/InterfaceTranslations.json` 存放按中文键检索的译文，`Models/Localization.swift` 负责语言、回退与格式化。新增含数字或昵称的文本使用格式模板，不把用户内容当翻译键重写。

`python3 scripts/check-localizations.py` 校验声明的语言、主要界面、20 道题、四级答案和格式占位符。UI 测试另验证英语问卷、切换后的持久化，以及阿拉伯语设置布局。自动检查不能替代母语审校。
