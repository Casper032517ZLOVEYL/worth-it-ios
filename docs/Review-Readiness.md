# 发布与审核准备（2026-10-22）

本轮按用户给出的 [CSDN 文章](https://blog.csdn.net/weixin_30516429/article/details/166428534) 核对微信平台配置，再与 [苹果官方审核指南](https://developer.apple.com/app-store/review/guidelines/) 和微信移动应用文档交叉核对。本文是工程核对记录，不表示已提交、通过审核或取得资质。

## 文章中适用的部分

文章为《微信开放平台 AppID 申请与配置全指南：从审核到联调避坑手册》。采用其中的应用类型、主体与应用信息一致、隐私政策、回调联调、凭据保护和真实测试要求。文章同时涉及网站、移动应用及小程序；本工程采用移动应用 AppID、Bundle ID、URL Scheme 与 Universal Link / AASA，不能套用网站 OAuth 回调域或小程序服务器域。文中的费用、处理时长等非官方断言没有固化进产品，应以开放平台实际页面为准。

客户端已接官方 OpenSDK，不含 AppSecret。当前没有真实 AppID、Universal Link、短信凭据或 HTTPS 后端，相关入口不会伪造授权或验证码；配置方式见 [微信接入](WeChat-Setup.md) 与 [短信接入](SMS-Setup.md)。

## 仍需真实条件，不能用占位内容提交

1. 填写 `APP_OWNER_NAME`、真实可访问的 `PRIVACY_POLICY_URL`、`SUPPORT_URL`、`SUPPORT_EMAIL`；按实际条款填写 `TERMS_OF_USE_URL`。当前未获得这些信息，预检查会失败，而非伪造主体或网址。
2. 决定发行版是否启用互联网登录。若启用，应部署并联调真实短信 / 邮件 / 微信服务，保证审核期间可访问，验证取消、过期、断网、换绑及删除。
3. 苹果指南 4.8 对以微信等第三方服务设置主要账号的情况有等价登录要求。当前“苹果绑定”只是未开放入口，**不属于已接入 Sign in with Apple**。本机档案不能自动当作已满足该条。启用微信对外发行前须落实适用的等价登录方式并联调；发布脚本对此明确阻断，不能仅填入 AppID 就提交。
4. 苹果指南 4.3 对同质化 / 饱和类别有要求。应以实际的决策反思、草稿和复盘功能说明独特价值，准确选分类、年龄分级和截图；添加娱乐文案不能保证通过审核。
5. 保留文本来源与改写记录，继续校勘古籍录文。正式发行需逐语审校、真机摇动体验、无障碍 / 多尺寸和真实账号测试。当前模拟器通过不代替这些验证。
6. 核实 App Store Connect 的隐私政策、客服、数据收集、SDK 与实际发行构建一致；无广告、无追踪，不要凭空声明业务能力或医疗效果。

## 预检查

构建后运行：

```sh
python3 scripts/check-release.py --app '/path/to/值得吗？.app'
```

脚本检查包内资源、语言、隐私清单、真实公开资料和微信启用条件。它不认证域名归属、资质或审核结果，不会自动发布 App。

原创问心签共 100 首，保留旧 1–12 签编号；其余为本项目新增原创文字。观音百签采用七言四句通行录文，古代传统内容参考 [百签汇录](https://www.fzlgo.com/guan-yin-ling-qian/)，并以 [农历网第四签](https://www.nongli.com/item5/guanyin/4.html) 对照用户指定版本。仅收录传统诗文及旧时条目，不导入网站现代长篇释义；现代行动解读和 100 则故事提要为本应用另写。民间故事不冒称经书或史实。应用内“版本与来源”同步给出链接及版本边界。
